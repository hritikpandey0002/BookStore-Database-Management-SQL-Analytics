#BookStore Database Management & SQL Analytics
This project demonstrates the design and analysis of an Online Bookstore relational database using PostgreSQL. It covers database creation, table relationships, data import from CSV files, and SQL queries ranging from beginner to advanced levels for extracting meaningful business insights.
The database consists of three related tables:
•	Books – Stores book details, pricing, genre, and inventory. 
•	Customers – Maintains customer information and location. 
•	Orders – Records customer purchases and order details.
The project includes SQL queries for:
•	Database and table creation 
•	Data import using COPY 
•	Data filtering and sorting 
•	Aggregate functions (SUM, AVG, COUNT) 
•	Joins between multiple tables 
•	Grouping and business reporting 
•	Inventory tracking 
•	Sales and revenue analysis 
•	Customer purchasing behavior 
•	Author and genre-wise sales insights
